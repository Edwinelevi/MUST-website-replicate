# MUST Website Replica — Application Portal

## Project Overview
This project is a front-end replication of the application portal of Mbarara University of Science and Technology (MUST). It was developed as part of my web development coursework to practise recreating an existing website interface using HTML and CSS.

The project focuses on reproducing the appearance and basic functionality of the login and account creation pages.

## Project Objectives
- To practise building web pages using HTML5 and CSS3.
- To replicate the design of the MUST application portal.
- To create navigation between the login and account creation pages.
- To apply semantic HTML elements and structured web forms.
- To implement basic form validation and password visibility functionality.
- To practise organizing website files and publishing a project using GitHub.

## Technologies Used
- **HTML5:** Used to structure the web pages and forms.
- **CSS3:** Used to style the interfaces, layouts, and visual elements.
- **JavaScript:** Used where applicable to support interactive functionality.
- **GitHub:** Used to store and share the project source code.

## Main Features
- A login page inspired by the MUST application portal.
- An account creation page linked to the login page.
- MUST university branding and logo on the login page.
- Form input fields with validation.
- A password visibility control.
- Consistent styling across the two interfaces.

## Project Files
- `index.html` — Contains the main login interface and its associated page structure.
- `style.css` — Contains the styling rules for the website interfaces.

## How to Run the Project
1. Clone or download this repository from GitHub.
2. Open the downloaded project folder.
3. Open `index.html` in a web browser such as Google Chrome.
4. Navigate between the login and account creation pages to explore the interfaces.

## Academic Purpose
This project is an educational replication of an existing university application portal. It is intended for learning and demonstration purposes and is not an official MUST website or a production application system.
